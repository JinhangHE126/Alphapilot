## 七、已知局限（跨里程碑）

1. **页码为估算**：字符位置比例推算；长年报可能有偏差
2. **表格并入 section 文本**：未独立 table chunk
3. **章节 `General`**：常见于港股季报 / markitdown 质量差场景
4. **跨语言检索**：`all-MiniLM-L6-v2` 对中文 query → 英文正文仍偏弱
5. **`eval_doc_recall.py`**：未实现
6. **M4 E2E**：手工验证，无 `test_recommendation_m4.py`
