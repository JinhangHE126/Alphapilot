## 一、核心发现

1. **财务质量扎实，估值已反映多数优势**：苹果营收同比增长 16.6%，每股收益同比增长 21.8%，净利率 27.15%，自由现金流超过 1,010 亿美元，净资产收益率 141.47%。当前市盈率 38.31 倍、市净率 43.43 倍，估值处于历史偏高位置。

2. **10-K 风险因素显示贸易与供应链影响已在兑现**：公司 2025 年 10-K 指出，国际贸易限制、关税及其他进出口管制**已对**业务与供应链产生重大不利影响，且预计将继续产生不利影响；相关措施**亦可能压制毛利率**。地缘紧张**已在部分产品线造成显著中断**，管理层预计其他地区与产品线仍面临进一步中断风险。

3. **年报对宏观与监管风险的表述偏审慎**：10-K 明确写道，公司运营与业绩严重依赖全球和区域经济状况；同时面临反垄断、数据隐私等复杂监管环境，不利诉讼或调查结果可能迫使公司调整商业惯例。

4. **文档证据强化下行风险判断**：年报风险因素措辞表明贸易与供应链风险**正在实质化**，而非仅停留在前瞻警示层面，这与当前高估值形成更突出的张力。

5. **综合判断：持有，但 filing 证据支持更防御性仓位**：基于年报风险措辞升级，策略评估维持 **Hold**，但对新增配置建议更保守。

**矛盾信号与加权判断**：

## 三、整体评估

**一句话摘要**：苹果财务质量卓越，但 10-K 最新风险披露表明贸易与供应链不利影响已在兑现，当前估值对上述风险的定价可能不足。

- **估值维度**：市盈率 38.31 倍、前瞻市盈率 32.82 倍，在风险实质化背景下容错空间更窄。
- **披露维度**：年报「已对业务产生重大不利影响」的表述，是本次评估的核心定性依据。
- **趋势维度**：股价 315.32 美元接近布林带上轨 321.2 美元，短期技术位置偏高。

## 四、个性化投资建议

**建议仓位**：总资产的 **2–3%**（中等风险偏好、中等投资期限）

**理由**：
- 10-K 风险措辞升级，支持低于常规水平的仓位配置。
- 财务质量仍支持中长期持有，但贸易与供应链风险已在兑现，不宜激进加仓。
- 当前技术位置与 filing 风险叠加，新增资金宜等待更明确信号。

**入场策略**：分 2–3 批建仓；建议在股价回落至布林带中轨 298.1 美元下方再考虑首批，并关注下一份季报中风险因素是否维持同等严重程度。

## 五、风险警告

1. **贸易与关税实质化风险**：10-K 披露相关措施已对供应链造成实质冲击，后续影响可能随政策演变而扩大。
2. **供应链中断风险**：地缘紧张已在部分产品线造成显著中断，制造集中度高放大尾部风险。
3. **监管与诉讼风险**：全球反垄断与隐私监管趋严，不利结果可能改变产品或商业模式。
4. **毛利承压风险**：管理层预计贸易相关影响可能继续压制毛利率，与当前高估值形成冲突。
5. **估值回调风险**：市盈率 38.31 倍处于高位，若风险持续兑现，估值与盈利可能双重承压。
